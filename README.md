# gtzideas-web

Páginas web públicas de las apps de GTZIdeas, servidas con GitHub Pages en
https://matthewgtz.github.io/gtzideas-web/. Una carpeta por app.

- `filmflip/`: política de privacidad y condiciones de FilmFlip. **No se editan
  aquí**: las genera `npm run legal -- ../gtzideas-web/filmflip` desde
  `src/data/legal.json` en el repo de la app.
- `index.html`: portada con enlaces a todo.
